Do SHAP and LIME agree?

Pick one S&P 500 stock, and either a past day whose outcome is already known — so the forecast can be scored — or the next trading session, which has not happened yet. The Random Forest forecasts that stock's next-day return, then TreeSHAP and LIME each explain the same forecast, live from the model rather than from a cached file. The page then tests whether the two explanations agree with each other, whether LIME says the same thing twice, and whether either is faithful to what the model actually uses.

Is each one stable?

LIME re-run five times on the identical input. TreeSHAP is deterministic, so re-running it is pointless — it returns the same numbers every time.

Is the explanation faithful?

The project's central test. Blank out the feature SHAP called most important and see how far the forecast moves; then do the same to random features. If the explanation is real, the first should move it far more.
